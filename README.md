# Strong Baseline (YOLOv12n + BoT-SORT-ReID)

Multi-UAV tracking in thermal infrared video. Based on
[wish44165/YOLOv12-BoT-SORT-ReID](https://github.com/wish44165/YOLOv12-BoT-SORT-ReID)
([paper](https://arxiv.org/abs/2503.17237)); trained weights are not included.
